# Nolawi Architects

A responsive static portfolio website for Nolawi Architects, focused on architecture, interiors and delivery.

## Run locally

Open `index.html` directly, or serve the folder with any static web server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Pages

- Home
- Selected work
- Individual project pages
- Studio
- Services
- Contact
